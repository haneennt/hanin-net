# حنين نت — نسخة النشر الاحترافية

## المتطلبات
- Node.js 18 أو أحدث
- استضافة تدعم Node.js وSQLite أو VPS

## التشغيل
1. فك الضغط.
2. نفّذ: `npm install`
3. انسخ `.env.example` إلى `.env`.
4. غيّر `ADMIN_PASSWORD` و`SESSION_SECRET`.
5. شغّل: `npm start`
6. افتح: `http://localhost:3000`

## النشر
ارفع المشروع إلى VPS أو خدمة استضافة Node.js، ثم شغّل `npm install` و`npm start`.
اربط دومينك، وفَعّل HTTPS، واجعل متغيرات البيئة سرية.

## ملاحظات مهمة
- الدفع الحالي عبر شام كاش بتأكيد يدوي.
- لوحة الإدارة تسلّم أول كود متوفر من الباقة عند تأكيد الطلب.
- لا ترفع ملف `.env` للعامة.
- قبل الاستخدام التجاري، أضف نسخاً احتياطية لقاعدة البيانات، وربط واتساب/رسائل، وسياسة خصوصية وشروط استخدام.
